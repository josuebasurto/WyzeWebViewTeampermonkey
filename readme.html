Instalación

1

Instala la extensión Tampermonkey en tu navegador.

2

Abre teampermonkey01.js, copia su contenido y crea un script nuevo desde el panel de Tampermonkey.

3

Guarda el script, entra a https://my.wyze.com/home y recarga con Ctrl + F5.

El script solo modifica la interfaz local del navegador. No cambia la cuenta, las cámaras ni la configuración del servicio Wyze.

Wyze Grid Enhancer

Columnas

Define cuántas cámaras aparecen por fila. El rango actual es de 1 a 8.

Separación

Controla el espacio entre cámaras con un control de menos y más. Inicia en 1 px.

Ocultar navegación

Retira la barra lateral y la navegación para aprovechar el área de visualización.

Minimizar

Usa el botón menos del encabezado para dejar el panel de configuración fuera del camino.

What's new

Problemas comunes

El panel no aparece

Comprueba que Tampermonkey esté activo para my.wyze.com. Después recarga con Ctrl + F5 y verifica que el userscript esté habilitado.

Las cámaras conservan su tamaño anterior

Cierra otras pestañas del portal y vuelve a cargar la página. Los cambios de columnas y separación se aplican automáticamente.

Quieres volver al diseño original

Desactiva el userscript desde Tampermonkey y recarga el portal. El botón Restablecer solo devuelve las opciones del script a sus valores iniciales.
